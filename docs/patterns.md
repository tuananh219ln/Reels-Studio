# Patterns & Conventions

## Project-Specific Code Patterns

- **Long-running work goes through the queue.** API handlers enqueue and return immediately; see
  [architecture.md](architecture.md#tech-stack) for which work runs in the worker and how
  rendering is composited.
- **Provider choice is configuration.** The ElevenLabs voice and model are selected by config; the
  LLM provider, its base URL and model are chosen on Cài đặt › Mô hình AI ([llm.py](../api/src/reels_api/llm.py)).
  Nothing is hard-coded. Stock sources are offered when their key is set and the team has not turned
  them off on Cài đặt › Nguồn tư liệu; the render core's CLI stays Pixabay-only.
- **Pages stay light on the web worker.** Every page render and every `/api` call passes through the
  OpenNext worker, which costs about a second or more per request in production. So pages poll with
  `usePolling` ([polling.ts](../web/src/lib/polling.ts)): the next poll waits for the previous
  answer, and a hidden tab does not poll. A page polls every few seconds only while something on it
  is being made or edited, and about once a minute otherwise (UI Rules, "Refresh"). Links are written `prefetch={false}`, since a prefetch is
  a full server render. Hashed build files are cached for good through
  [web/public/_headers](../web/public/_headers).
- **A page's view in the address is read with `useSearchParams`.** For example `/posts?view=calendar`.
  Read it inside a `Suspense` boundary, never through a client page's `searchParams` prop: that prop
  does not follow `router.replace` to the same page, and on a page prerendered as static it is empty
  in the production build, so the view works in `next dev` and breaks in E2E and production.
- **Attribute adapted code.** Code adapted from MoneyPrinterTurbo keeps its MIT attribution in the
  file header.
- **Prompt content is app data; the output format is code.** Members edit the prompt text and the
  banned words on `/knowledge`; the JSON output format and its example stay fixed in
  [claude.py](../api/src/reels_api/claude.py), so an edited prompt can never break the
  parsing every job depends on. See [content.md](content.md#script-generation-contract).
- **Claude, Pixabay, ElevenLabs, and Facebook are reached only through their base URL in tests.** The other
  LLM providers are reached the way members set them up, through the base URL saved on `/settings/ai`,
  pointed at the fake's OpenAI-compatible API (`<fake>/openai/v1`). Tests and
  E2E point `ANTHROPIC_BASE_URL`, `PIXABAY_API_URL`, `ELEVENLABS_API_URL`, and `FACEBOOK_API_URL` at a local fake server; production code has no test
  switches.

## Git Workflow

The default branch is `main`. Branch, commit and PR rules are in [AGENTS.md](../AGENTS.md#git).
A bigger feature carries its plan in the PR description; the early features' specs are kept as
history in [specs/](specs/).

### Quality Gates

[ci-cd.yml](../.github/workflows/ci-cd.yml) runs lint and format checks (ruff for api
and worker with the repo-root `ruff.toml`; ESLint with the Next.js config and Prettier for web), the
typecheck, the api, worker,
and web tests (with E2E and the Cloudflare build) on every PR; a push to `main` deploys only after
all of them pass.

## Testing & Verification

- **Backend:** pytest.
- **Render smoke test:** renders a short MP4 from images generated by Pillow and checks it with
  `ffprobe` and extracted frames. This is the guard against silent pipeline breakage. Tests live
  in [worker/tests/](../worker/tests/) and run with `pytest` from `worker/`. Tests that
  need FFmpeg are skipped, with a reason, when `ffmpeg`/`ffprobe` are not on PATH. Run them with
  FFmpeg present before merging render changes.
- **Sample render:** [samples/xuong-khop.json](../samples/xuong-khop.json) and its
  committed images render end to end with the CLI. The api's render parity test loads the same
  sample into the database and storage, renders it through the worker path, and requires the MP4 to
  match the CLI's (same length and size, mid-scene frames within 3/255) and the first frame to
  match the title preview.
- **api** ([api/tests/](../api/tests/)): pytest on real Postgres. Endpoint tests run in a
  rolled-back transaction; worker tests commit for real and start real `python -m reels_api worker`
  processes, with fake Claude/Pixabay over HTTP and stand-in `ffmpeg` scripts for hangs and
  failures. They need `TEST_DATABASE_URL` and FFmpeg; CI fails if any of them is skipped.
  `pytest -n 4` (pytest-xdist) runs them in parallel on one machine: each process migrates its own
  database, `TEST_DATABASE_URL`'s name plus `_gw0`, `_gw1`..., created on first use.
  `PYTEST_SHARD=i/n` keeps every n-th test from the i-th; CI uses it to split the suite over four
  machines.
- **Frontend:** Playwright E2E covers the main flows; it starts the api, a real worker, and the fake
  Claude/Pixabay ([web/playwright.config.ts](../web/playwright.config.ts)), so FFmpeg is
  needed there too. Every test resets `reels_e2e` first, so any subset runs on its own: CI splits
  them over four machines, and locally `-g "<title>"`, a single spec file or `--last-failed` runs
  just the tests a change touches.
- **E2E locators that hold.** Every rule here comes from a CI failure. Find elements by role or
  label scoped to their area (a card, a dialog, `getByTestId(...)`), with `exact: true` for short
  names. A name that also appears elsewhere on the page (a header button and an empty-state button,
  a hover tooltip and a confirm popover) breaks strict mode once the UI changes. Read an antd choice
  from its radio (`toBeChecked`), not from a class such as `.ant-segmented-item-selected`, which is
  missing while it animates. Use the app's Vietnamese labels ("Đóng"), never antd's English ones.
- **Run the E2E tests a UI change touches before pushing.** Run them with `-g "<title>"` or a spec
  file. A selector broken by a UI change otherwise shows up only on CI, and on `main` once merged.
  Locally E2E needs Postgres at `E2E_DATABASE_URL` (default `reels:reels@127.0.0.1:5432/reels_e2e`,
  the `docker-compose.yml` one). If port 5432 is taken by something else, point
  `E2E_DATABASE_URL` at a free Postgres instead.
- **Visual template check:** a person watches a rendered MP4 against the template in
  [ux-guidelines.md](ux-guidelines.md#video-template). An agent cannot judge the visual result.
