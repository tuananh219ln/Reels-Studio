# ChatGPT connection

Reels Studio exposes a private MCP connection for ChatGPT. Members authorize it with their
existing Reels Studio account. The connection can read videos and topic groups, edit video
and scene text, and enqueue script and render jobs through the same rules as the editor.

Implementation and verification are tracked in the draft PR. Setup instructions will accompany
the finished integration. Posting, deleting videos, and changing credentials are outside this
connection's scope.
