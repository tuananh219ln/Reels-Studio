# 2026-11-25 — Custom Link is in the "Nhập / Xuất" menu again

Asked by a member: Shopee's Custom Link page takes only its Excel template, and on Affiliate › Sản phẩm the
"Nhập / Xuất" menu offered only "Xuất CSV", which Shopee refuses. The Excel export existed, but since
[2026-11-25-products-board](2026-11-25-products-board.md) it was only at the head of the board's "3 · Cần link" column,
which shows nothing when every product already has a link, so it could not be found and "Gồm cả món đã có link" could
not be reached at all.

- "Nhập / Xuất" lists **"Xuất file Custom Link (Excel)"** and **"Nhập kết quả Shopee"** (the same dialogs as the
  column's buttons, which stay), greyed with "Chọn một nhóm chủ đề ở trên trước" until a group is open.
- **"Xuất CSV" is renamed "Xuất danh sách (CSV)"**, so the list to read is not mistaken for the file to upload.
- Nothing changes in the api: the export, the Page choice, the 10,000-link limit and the CSV/Excel import are as in
  [2026-11-24-custom-link-excel](2026-11-24-custom-link-excel.md).
