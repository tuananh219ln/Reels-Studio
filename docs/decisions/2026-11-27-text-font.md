# 2026-11-27 — "Phông chữ" of the text boxes: Be Vietnam Pro or Bungee

Asked by tuananh219ln: the text of the "Sức khỏe" groups in Bungee.

- **A video option, `text_font`** (`be_vietnam` default, `bungee`), one of the look fields next to "Cỡ chữ" and "Dạng chữ": the video's Thiết lập,
  Cài đặt › Thiết lập mặc định, a group's "Chữ & phụ đề" card and `set_video_options`. The code does not know which groups are
  "Sức khỏe" (it never named them), so the font is **set on those groups' cards**, not hard-coded by name; every other group and every
  video made before stays Be Vietnam Pro Black. Production data is not touched by this change.
- **Drawn in the text boxes**: the title box (the "Tiêu đề động" hook too) and the content scenes' boxes. The fit is measured in the chosen font
  everywhere a text is checked (`script_rules.text_problem`, `frames`, the preview, the render), so Bungee, which is wider, shrinks or wraps
  as needed instead of failing at render. **Not covered**: phrase and word captions, text layers, and PC Shopee's compact text, whose looks
  have their own fonts ([pc-text-styles](2026-11-27-pc-text-styles.md)).
- **A render machine on older code refuses it** (`text_font` is sent only when it is not the original). The MP4 fingerprint and the preview
  addresses hold it only while it is not the original (it is a look field).
- The AI that suggests a group's look may choose it too (`text_looks.VALUE_NOTES`).
