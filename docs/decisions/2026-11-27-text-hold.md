# 2026-11-27 — "Ẩn chữ sau X giây" for the topic group PC Shopee, built first from the spec "Ẩn chữ & Phụ đề Cộng dồn"

The spec (Looper, 2026-11-27, `Spec_PC_Shopee_An-chu_Phu-de-Cong-don.md`) has three rounds; this is round 1, which it says
to do first. Rounds 2 (the "Cộng dồn" captions and the three new text styles) and 3 (the 3-tier title and 2-tier scene
text) are not built and need their own decisions (word timestamps from ElevenLabs, a new caption renderer).

- **The group is found by its name, "PC Shopee"** (case and spaces ignored, `video_options.is_pc_shopee`), not by a new
  flag: the spec allowed "a flag or equivalent", and a name keeps this to no new column on `knowledge_topics`. Renaming the
  group turns the feature off for new videos; videos already made keep their saved setting.
- **Where it is stored.** The video's own `options.text_hold_sec` (null by default, so every video before and every other
  group's renders as before, and the MP4 fingerprint leaves it out) and the scene's `scenes.text_hold_sec` (migration
  0139, null: the video's). A new PC Shopee video starts at 2.5 (`apply_defaults`). The order is scene › video; the spec's
  third level, a group setting, is the constant 2.5 for now, not editable.
- **The render.** The api sends each scene's resolved `text_hold_sec`; the render core fades that scene's text box (the
  same picture as the dark band) out after X, 0.25 s long (`graph.hold_seconds`). The title and last scenes are never
  held, nor a scene whose X is within 0.3 s of its end. A render machine on older code refuses the video (`text_hold`
  option, sent only when on), as for `text_shade`, instead of keeping the text all scene.
- **Left out on purpose:** the 96% shrink during the fade (FFmpeg's overlay cannot scale an animated picture without
  rebuilding the text as an animated layer; the fade alone reads the same at 0.25 s). The title scene was already 3 s.
- **A person watches the render** (AGENTS.md): a sample PC Shopee MP4 against the spec's round-1 checklist, and an MP4 of
  another group re-rendered and compared with the one before, are still to be done by a person.
